# # Дипломный проект Яндекс.Практикум. UI e2e-тесты приложения Яндекс.Маршруты

Проект содержит автоматизированные end-to-end тесты пользовательского интерфейса сервиса [Яндекс.Маршруты](https://qa-routes.education-services.ru/). Тесты проходят основные пользовательские сценарии в браузере: от построения маршрута до оформления заказа такси и проверки экрана поездки. Это помогает проверить, что ключевые элементы интерфейса отображаются, переключатели работают, а данные заказа согласованы между экранами.

## Что тестируется

- Построение маршрута по начальной и конечной точкам и отображение точек маршрута на карте.
- Появление панели выбора транспорта, в том числе для одинаковых адресов.
- Переключение режимов «Оптимальный», «Быстрый» и «Свой», доступность видов транспорта и пересчёт маршрута.
- Отображение тарифов, выбор тарифа и наличие полей формы заказа.
- Текст подсказок у тарифов.
- Экраны поиска автомобиля и активной поездки: заголовки, таймер, данные автомобиля и водителя, кнопки управления.
- Соответствие стоимости в деталях поездки выбранному тарифу и закрытие панели после отмены поездки.

Проверки подсказок тарифов «Разговорчивый» и «Сонный» помечены как `xfail`: в тестовом приложении для них известен дефект текста.

## Стек

- **Python 3.14** — язык программирования.
- **pytest** — запуск тестов, параметризация сценариев и фикстуры подготовки браузера и приложения.
- **Selenium WebDriver** — взаимодействие с интерфейсом браузера.
- **Page Object Model (POM)** — паттерн проектирования для организации кода тестов.
- **Allure** и `allure-pytest` — генерация отчётов тестирования в формате Allure.

Тесты запускаются в обычном, не headless-режиме. Для их выполнения необходим установленный Google Chrome и доступ к тестовому приложению по сети.

## Установка и запуск

1. Клонируйте репозиторий или скачайте проект и перейдите в каталог `Sprint_10`.
2. Создайте и активируйте виртуальное окружение (macOS/Linux):

```bash
python3 -m venv .venv
source .venv/bin/activate
```

В Windows PowerShell окружение можно активировать командой:

```powershell
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Запустите все тесты из корня проекта:

```bash
pytest -v
```

Чтобы выполнить отдельный набор, например тесты режимов маршрута:

```bash
pytest -v tests/test_mode_switching.py
```

## Allure-отчёт

Плагин Allure для pytest устанавливается вместе с зависимостями проекта. Для просмотра отчёта дополнительно установите Allure Commandline и убедитесь, что команда `allure` доступна в терминале.

```bash
pytest -v --alluredir=allure_results
allure serve allure_results
```
